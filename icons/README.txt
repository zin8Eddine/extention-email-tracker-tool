ICON FILES NEEDED
=================

Place the following icon files in this directory:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)  
- icon128.png (128x128 pixels)

To generate these icons:
1. Open ../create-icons.html in your web browser
2. The icons will automatically download
3. Move them to this icons/ folder

The extension will work without these icons, but Chrome will show a default icon.
